HRMS API Tester

A plain static page for trying the NestJS API by hand. It sends the x-acting-user header on every call. Nothing here is stored on a server.

The page cannot reach the API?

The easiest way is to open this page from the API itself, for example http://localhost:3000/apiTester.html. The page and the API then share one address, so no CORS setup is needed.

A page opened from a file or from another port is a different origin, so the browser only lets it read the API's answer if the API sends CORS headers. In that case add app.enableCors(); in webapp/src/main.ts before app.listen and restart the API.
